# Google Sheets 共有商品管理の設定

このフォルダーの `Code.gs` と `Admin.html` を Google Apps Script に配置すると、商品一覧を Google Sheets で管理できます。商品一覧の公開と管理画面の更新には、Apps Script のウェブアプリをデプロイする必要があります。

## 初回設定

1. Google Sheets で商品管理用のスプレッドシートを作成し、URL の `/d/` と `/edit` の間にある ID を控えます。
2. 拡張機能 → Apps Script を開き、`Code.gs` の内容を貼り付けます。HTML ファイル `Admin` を追加し、`Admin.html` の内容を貼り付けます。
3. Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に次を登録します。
   - `SPREADSHEET_ID`: 作成したスプレッドシートの ID
   - `ADMIN_PASSWORD`: 仮パスワード `1989`
4. エディタで `setupCatalog` を選択して実行し、スプレッドシートへのアクセスを許可します。商品シートと初期商品が作成されます。
5. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選びます。「次のユーザーとして実行」は自分、「アクセスできるユーザー」は全員にしてデプロイします。発行された URL が `/exec` で終わることを確認します。
6. 公開サイトの管理画面は、その URL に `?page=admin` を付けて開きます。初回ログイン後、12文字以上の管理者パスワードに変更してください。
7. `script.js` の `sharedCatalogApiUrl` にウェブアプリの `/exec` URL を設定してサイトを再公開すると、商品一覧がシートと連動します。

## 注意

- ウェブアプリは商品一覧を公開し、管理操作はパスワード認証します。シート自体は公開共有せず、Apps Script の実行者だけがアクセスできる状態にしてください。
- 仮パスワード `1989` のまま管理操作はできません。初回ログイン時に変更が必要です。
- 注文送信はサイトからメールアプリの下書きを開く方式です。メールの送信自体は注文者が行います。
- 商品データの画像・詳細ページ URL は、サイトから参照可能な相対パスまたは HTTPS URL を指定してください。
